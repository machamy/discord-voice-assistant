아짱·클짱 — 실사용 개선 연구

2026-10-15 · 실사용 로그(4~5명 게임 잡담) 분석 + Codex 독립 코드 감사(gpt-5.6-sol xhigh, 읽기 전용) + 서브에이전트 웹 조사(받아쓰기·호출어 / 판단 모델·지연 / 페르소나). 추정 표시는 실측이 아니다.

18종"클짱·아짱" 받아쓰기 변형 (실장·휘장·필장·클잭·악장…)
  • 지연: 대답 처리기가 하나뿐이고 앞 대답의 음성 재생이 끝날 때까지(8~12초) 다음 호출을 시작하지 않는다. Codex는 edge-tts의 8초×2 재시도도 같은 크기의 원인으로 지목했다. 둘 다 코드로 확인된다.
  • 호출 인식: "클짱"은 Whisper가 모르는 지어낸 낱말이라 비슷한 실제 낱말로 끌려간다. 모델을 바꿔도 크게 안 줄어든다(FLEURS 한국어 CER: turbo 5.24 / large-v3 4.89 / Qwen3-ASR-1.7B 4.60). 텍스트 힌트는 환각을 만든다(실측 63%/25%).
  • 추천: ① 대답 생성과 재생 분리 + 최신 호출 우선 ② 점수형 호출 판정(위험 별칭 등급·ASR 신뢰도·문맥, 애매할 때만 LLM 판단) ③ 짧은 조각 합치기·잡음 사유 분리 ④ edge-tts 재시도 제거·회로 차단기 ⑤ 호출 시점 컨텍스트 고정·출력 검증 ⑥ 페르소나를 캐릭터 카드 구조로.
  • 버튼 호출: 디스코드 음성 채널 이모지 반응·사운드보드 이벤트(VOICE_CHANNEL_EFFECT_SEND)로 설치 없이 "딸깍" 호출이 가능할 수 있다(serenity 지원 여부 확인 필요).

대화 품질 · 비용

  • 호출 시점 컨텍스트 고정: 지금은 대답 처리기가 나중에 버퍼를 다시 읽어, 대기 중 나온 "미래 대화"가 섞이고 질문이 기록과 질문란에 두 번 들어간다.
  • 기록은 "믿지 않는 데이터"로 구분해 전달(음성으로 들어온 지시문이 명령처럼 먹히는 프롬프트 주입 완화).
  • 출력 검증: <말>/<글> 형식 강제, 지시문·태그 노출 시 한 번 다시 생성. 기본 max_tokens 1500 → 400~600, 800자 서버측 절단.
  • 기억 도구 이중 확인: 질문에 "기억해/잊어" 의도가 실제로 있을 때만 적용. 기억은 부른 사람·대화에 나온 사람 것만 넣기.
  • 반복 억제: Groq는 frequency/presence penalty 미지원 → 직전 대답 몇 개를 넣고 비슷하면 재생성.
  • 비용: /모델로 누구나 유료 프리셋(sonnet·opus)을 고를 수 있다 — 오늘 opus 1회 약 $0.035. 유료는 관리자만, 또는 하루 상한을 더 낮게.
  • 캐시: 시스템·페르소나 전용 캐시 지점 분리, 캐시 적중률을 웹 콘솔에 표시.

페르소나 — AI 챗 캐릭터 방식

조사 결론(SillyTavern 캐릭터 카드 V2/V3, Character.AI 정의, RisuAI·국내 캐릭터 챗 가이드, AI 버튜버 kimjammer/Neuro·Open-LLM-VTuber, LiveKit·OpenAI 실시간 음성 프롬프트 가이드, Anthropic 문서):

  • 형용사보다 예시 대화가 말투를 만든다(Ali:Chat, Anthropic "예시가 가장 믿을 만한 조종 수단"). 예전 페르소나는 형용사 3줄뿐이었다.
  • "가끔, 과하지 않게"는 말버릇을 0으로 수렴시킨다 → "한 대답에 하나쯤 + 후보를 돌려 쓰기".
  • 꺾쇠 안 설명문(<말>음성으로 읽을 1~2문장…</말>)을 작은 모델이 그대로 옮긴다 → 형식은 예시로만, 설명은 꺾쇠 밖.
  • 질문 바로 뒤 한 줄 상기 문구(SillyTavern post_history_instructions, CCv3 @@depth 0) — 대화가 길어져도 말투 유지. 캐시 지점 뒤라 비용이 거의 없다. Groq gpt-oss는 우리 system이 developer 등급으로 들어가 특히 효과가 크다.
  • "이것만 사실이다" 목록 + 모를 때 할 대사로 자기 설정 지어내기 차단(검색·도구 없음도 명시).
  • 같은 말 되풀이 금지 규칙을 따로(OpenAI Realtime 가이드의 Variety 규칙).

적용(10/15): 클짱·아짱 페르소나를 캐릭터 카드 구조(정체성 → 행동으로 쓴 성격 → 말투 규칙 → 좋아함/싫어함 → 관계 → 내가 아는 나 → 예시 6개 → 금지)로 교체(각 약 2,100자), 공통 규칙에서 꺾쇠 안 설명문 제거·되풀이 금지 추가, 캐릭터별 reminder 설정 추가. 웹 콘솔 말투 한도 1,500 → 3,000자, 기본값과 같은 말투는 덮어쓰기로 저장하지 않게 고침(웹 콘솔 저장 때 옛 기본값이 서버 덮어쓰기로 박혀 새 페르소나를 가리던 문제).

#작업기대 효과난이도

3점수형 호출 판정(별칭 안전/위험 등급) + 애매할 때만 Groq 판단 모델 + 판정 근거 기록·피드백 버튼놓침·오호출 동시 감소중간
4페르소나 캐릭터 카드 구조(예시 대화·말투 규칙·대답 직전 상기 문구) + 출력 검증·재생성말투·반복·지시문 노출낮음~중간
5짧은 조각 합치기, 호출 시점 컨텍스트 고정, 기록 2~3분으로짧은 호출 보존·첫 토큰 단축중간
6재시작 자동 재입장·작업자 감시·LAN 콘솔 차단·고지문운영 안정중간
7버튼·이모지 호출(VOICE_CHANNEL_EFFECT_SEND) → 데스크톱 단축키 도우미확실한 호출 수단중간
8(측정 후) sherpa-onnx 2차 호출어 검출, Qwen3-ASR-0.6B·large-v3 속도음향 단위 호출어높음
