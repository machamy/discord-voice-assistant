# 두뇌(LLM) 지연·캐시 실측 — 2026-10-13

봇 코드 경로 그대로 잰 값이다. 웹 콘솔 두뇌 시험 `POST /api/llm-test`를 보조 PC(`DESKTOP-Bed`)에서 불렀다(로그인 후 같은 PC의 `127.0.0.1:8694`).
질문은 기본값 "오늘 저녁 메뉴 하나만 추천해 줘."를 썼다. `fill`은 가짜 대화 기록 160줄을 붙여 캐시를 확인하는 옵션이다.
- `말 도착`은 요청 시작부터 스트림에서 `<말>…</말>`과 `<글>` 시작까지 받은 시점이다(SPEC F-26, 이때 TTS가 시작됨).
- `전체`는 대답이 끝날 때까지다.
