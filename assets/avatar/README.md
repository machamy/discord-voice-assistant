## v2가 따른 커뮤니티 설정 (디시콘 검색 2026-10-12)

`dccon.dcinside.com`에서 "클로드"·"아스트라"로 찾은 패키지 10개를 훑어 **여러 작가가 공통으로 쓰는 특징만** 뽑았다.
디시콘 이미지는 생성 모델에 넘기지 않았고 특징을 글로만 줬다(특정 작가 그림 모방 방지).

- **클로드**: 은발/애쉬 긴 웨이브 머리, 금색 별빛 장식이 달린 검은 리본, 흰 블라우스 + 검은 조끼(다크 아카데미아),
  여유 있는 "정답 아는" 표정, 안경. 패키지 170749(Hongcc)·174094(사슴뿔드래고니안)에서 반복.
  → v2에는 Anthropic 테라코타색을 넥리본으로 더함.
- **아스트라**: 검은 히메컷 긴 머리, 흰 머리띠, 빨간 재킷 + 금장식, 금귀걸이. 패키지 175416(teeteetee)·149361(네코마타)에서 반복.
  (은발 단발 + 파란 눈 치비 계열도 175279·175546에 있음)
