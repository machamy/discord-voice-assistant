날짜별

받아쓰기 체인

    힌트를 주면 그 말로 더 잘 받아쓰지만, 짧은 소리에서 힌트 말을 지어내 엉뚱하게 부를 수 있어요. 오른쪽 숫자(ms) 이상 발화에만 써요.

    목소리 체인

      키 등록 여부

      키 값은 화면에 나오지 않아요. 바꾸려면 보조 PC의 .env를 고친 뒤 재시작.

      판단 모델 (이름이 애매하게 들렸을 때 "정말 부른 말인가"를 작은 모델에 물어봄)

      판단 전용 모델은 "부름" 확률(0~1)을 내고, 기준 확률 이상이면 부른 것으로 봐요. 기준을 올리면 덜 부르고(잘못 부름↓), 내리면 더 잘 불러요(놓침↓). 비워 두면 모델별 추천값. 유료 판단 모델 비용은 하루 사용액에 더해지고, 상한에 닿으면 판단 없이 원래 규칙대로예요.
      헤이를 붙인 호출·이어서 말하기·이모지 호출은 묻지 않아요. 모델이 늦거나 실패하면 원래 규칙대로 대답해요. 판단 결과는 대화 탭 받아쓰기 상황·호출별 지연에 보여요.

      받아쓰기 상황 (발화마다 결과 · 글 내용은 아래 대화에만)

      호출별 지연 (말 끝 → 첫 소리, ms)

      두뇌 입출력 원문 (최근 20건 · 메모리에만 · 대화와 같이 지워짐)
